# Live Studio

Симулятор прямого эфира Instagram для съёмки контента: интерфейс эфира, растущий счётчик зрителей, комментарии от постоянных зрителей-персонажей и реакция чата на голос ведущего.

Ставится на телефон как приложение (PWA) — запускается во весь экран, без адресной строки, работает офлайн.

## Что умеет

- **Интерфейс** — плашка «Эфир», счётчик зрителей, закреплённый комментарий, стопка аватарок, комментарии с фото профиля, летящие сердечки, диалог «Завершить прямой эфир?»
- **Постоянная аудитория** — 18 зрителей со своими характерами: технарь комментирует звук, скептик сомневается, новичок переспрашивает. Ники и аватарки не меняются в течение эфира
- **Реакция на голос** — анализ громкости (чат оживает, когда говоришь; спрашивает «алло?», когда молчишь) и распознавание речи с реакцией на смысл сказанного
- **Умные ответы** — с подключённой LLM зрители отвечают на конкретную фразу в своём характере; без неё работают встроенные шаблоны
- **Мелочи** — задержка «печатает» пропорциональна длине реплики, случайные опечатки, обращения `@ник`, спам-бот с рекламой
- **Режимы** — ведущий или зритель чужого эфира, фейковый статус-бар iPhone, фон с камеры / из галереи / градиент

## Публикация на GitHub Pages

Бесплатный HTTPS-хостинг — этого достаточно, отдельный сервер для самого приложения не нужен.

1. Создать репозиторий на GitHub (публичный — для Pages на бесплатном тарифе).
2. Залить файлы:

```bash
git init
git add .
git commit -m "Live Studio"
git branch -M main
git remote add origin https://github.com/USERNAME/live-studio.git
git push -u origin main
```

3. В репозитории: **Settings → Pages → Source → GitHub Actions**.
4. Через минуту приложение будет доступно по адресу `https://USERNAME.github.io/live-studio/`.

Дальше каждый `git push` в `main` обновляет сайт автоматически.

### Установка на телефон

- **iPhone:** открыть адрес в Safari → «Поделиться» → «На экран "Домой"»
- **Android:** Chrome → меню → «Установить приложение»

Разрешения на камеру и микрофон запрашиваются один раз и запоминаются.

## Подключение LLM (по желанию)

Без этого шага чат работает на шаблонах — уже достаточно живо. С LLM зрители отвечают на смысл сказанного.

**Ключ нельзя вписывать в `index.html`** — исходник страницы открыт всем. Поле «Ключ напрямую» в настройках существует только для локальных тестов; для публичного адреса нужен прокси.

Прокси лежит в `proxy/`, ставится на любой VPS:

```bash
git clone https://github.com/USERNAME/live-studio.git /opt/live-studio
cd /opt/live-studio
python3 -m venv venv
venv/bin/pip install -r proxy/requirements.txt

cp proxy/live-proxy.service /etc/systemd/system/
# отредактировать: вписать ключ и свой адрес Pages в ALLOWED_ORIGIN
systemctl enable --now live-proxy
```

Nginx перед ним:

```nginx
location /chat {
    proxy_pass http://127.0.0.1:8787;
    proxy_set_header Host $host;
}
```

В настройках приложения в поле «Адрес прокси» вписать `https://твой-домен/chat`.

Поддерживаются Anthropic и OpenAI — переключается переменной `PROVIDER`, см. `proxy/.env.example`.

### Расход

Вызов происходит не чаще раза в 7 секунд и только для фраз длиннее четырёх слов: примерно 700 входных и 150 выходных токенов. Часовой эфир — доли доллара на младшей модели.

## Настройка под себя

Всё редактируется прямо в `index.html`:

| Что | Где | Зачем |
|---|---|---|
| `CAST` | ~строка 240 | состав аудитории: ник, характер, `w` — частота, `e` — доля эмодзи, `v: 1` — синяя галочка |
| `BY_ROLE` | ниже | офлайн-реплики конкретного зрителя |
| `TRIGGERS` | ниже | мгновенные реакции на ключевые слова |
| `SPAM` | ниже | реклама от бота раз в ~47 секунд |

Характер из `CAST` уходит в промпт LLM — достаточно описать зрителя словами, и он начнёт писать в своём стиле.

## Ограничения

- Распознавание речи работает в Chrome и Safari; в Firefox остаётся режим «Громкость»
- Камера и микрофон требуют HTTPS — на GitHub Pages это уже есть
- Файл, открытый как `file://`, камеру не получит: нужен хотя бы `python3 -m http.server` для локальной проверки

## Назначение

Инструмент для съёмки контента и репетиций: снять сторис «как будто в эфире», проверить кадр и подачу до настоящей трансляции, отрепетировать выступление с ощущением аудитории.

Это не настоящий эфир, и зрители не настоящие. Не стоит выдавать записанное за реальную трансляцию с живой аудиторией: это вводит зрителей в заблуждение и в рекламных материалах подпадает под запрет недостоверной рекламы.
